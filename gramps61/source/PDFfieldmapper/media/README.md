# PDFForms

PDFForms lets you take genealogy data entry **off the computer and onto paper (or a PDF viewer)**, then bring the results back into Gramps.

You generate a blank, fillable PDF form from inside Gramps, fill it in by hand or in any PDF viewer (a transcribed census page, a pedigree chart worked out at a family gathering), and import the completed PDF back into your tree.

The addon provides two plugins:

| Plugin | Type | Where to find it |
|---|---|---|
| **Generate PDF Forms** | Tool | Tools → Utilities → Generate PDF Forms |
| **Import Fillable PDF Forms** | Importer | Family Trees → Import |

## Requirements

- Gramps 6.1 or later
- The **Form** addon (provides the census/event form definitions and the Forms gramplet)
- The Python package **ReportLab** (used to draw the PDFs)

The Addon Manager installs ReportLab automatically when you install PDFForms. The Form addon is a separate addon and should be installed first.

> **Restart note:** after installing the Form addon, or after adding the Forms gramplet to a bottom bar, restart Gramps before importing a census/event PDF. Until then the import can fail with an error.

## Generate PDF Forms (Tool)

Open **Tools → Utilities → Generate PDF Forms** and choose one of two modes.

### Census / Event Form

Creates a blank fillable PDF from any form known to the Form addon: the built-in definitions (US, GB, CA, BE, DK, FR, PL) or your own custom XML forms.

- Pick the form.
- Choose the number of data rows.
- Generate the PDF.

The form's heading fields (for example Schedule, Enumeration District, Township, County) and its data columns are laid out as PDF form fields. Forms with person, family, and multi-row sections are all supported.

**Wide forms are handled automatically.** Forms with many narrow columns (such as the 42-column Canadian 1851 census form) are laid out on a wider page so every column stays readable:

- Each field is kept between a minimum and a maximum width (maximum 100 pt, roughly 20 characters).
- The page only grows as much as needed. Simple forms, such as the US 1790 census, stay on a standard A4 landscape page.
- All heading fields remain on-screen regardless of how wide the data section is.
- Forms that run past the bottom of a page continue on a new page.

### Ahnentafel Pedigree Chart

Creates a pedigree chart PDF for 1 to 5 generations. Each ancestor has fields for name, birth, marriage, and death, numbered in standard Ahnentafel order.

### Options

The tool remembers your last-used settings between sessions:

- last form chosen
- number of data rows
- number of generations
- output path
- whether to open the PDF in your system PDF viewer after generating

## Import Fillable PDF Forms (Import)

Use **Family Trees → Import** and select a completed PDF that was generated by this addon. The importer detects which kind of form it is.

### Census / Event forms

The field values are handed to the Form addon, which creates the data the same way as if you had typed it into the Forms gramplet. Heading values populate the Headings tab and the Reference field.

### Pedigree charts

The Ahnentafel fields are converted into Gramps objects, using Gramps' CSV import machinery:

- Persons
- Families
- Events (birth, marriage, death)
- Citations

### The source PDF is kept with your data

The imported PDF is copied into your Gramps media directory, and a media reference to it is added to every object the import creates. You can always get back from a person or event to the original form it came from.

## Known behaviour and limitations

- **Importing the same PDF twice creates duplicate data.** Persons and events are duplicated, as with importing any regular Gramps data twice. For census/event forms, a Source is also created for each import; the community discussion is leaning toward reusing a single Source per form definition, but this is not settled. Use Gramps' merge tools to clean up if you re-import.
- Census/event import depends on the Form addon being installed and loaded (see the restart note above).
- Only PDFs generated by this addon can be imported, because the importer relies on the field names the generator writes.
- A wiki help page for end users is still to be written.

## Developer notes

- PDFs are built with ReportLab; layout logic lives in `generate_pdf.py`.
- Unit tests are in `PDFForms/tests/test_generate_pdf.py`. They run standalone (no Gramps installation required) and skip automatically if ReportLab is not installed. Run them from the addons-source root with:

  ```bash
  python3 -m unittest PDFForms.tests.test_generate_pdf
  ```

  ReportLab must be importable by the Python you run the tests with; a copy installed by the Addon Manager into the Gramps plugins folder is not on the system path.

- Regression tests cover form listing and loading, column-width and text-wrapping helpers, generation for all three section types (multi, person, family), and the multi-page overflow path.
