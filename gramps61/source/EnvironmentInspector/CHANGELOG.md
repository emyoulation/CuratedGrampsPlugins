# Change log (Environment Inspector)
[README.md](README.md) ● [CHANGELOG.md](CHANGELOG.md) ● [Constants](media/EfficientConstants.md)

## 2.1.0 (2026-11)
- **Restart now no longer loses unsaved edits.** Before restarting, every open editor with unsaved changes asks whether to save them, even when "Do not ask again" was chosen before. If you cancel, or a save fails, the restart is cancelled and the language choice stays pending.
- **New Locale Settings tab**, the second tab. The language is only one of the settings that make up the locale Gramps uses. This tab lists the others in groups: the translation order and encoding; the locales for dates, numbers and currency; sorting, with the PyICU and ICU versions; spell checking, with the dictionary Gramps picks and the installed dictionaries; text direction, both for GTK and for Gramps; the locale-related Gramps preferences (date format, calendars, name and place formats, surname guessing, paper); and the environment variables that Gramps reads at startup. Hover over a setting to see where it is normally set: the Preferences tab and option, a right-click menu, a report dialog, the desktop settings or an environment variable. The tab reads the values again each time it is shown, keeping collapsed groups collapsed; right-click for **Expand all Nodes** and **Collapse all Nodes**, and **Copy table** copies everything as text.
- **New Help tab**, the last tab. It shows this README, translated when a translation exists. With the MarkdownUtils addon installed and enabled, the README is formatted, with images and working links (links to other help pages, such as the navigation links at the top of each page, open in the tab); otherwise it is shown as plain text, under a red alert that says whether MarkdownUtils is missing or deactivated and how to install or activate it. Turning MarkdownUtils on or off in the Plugin Manager takes effect the next time the tab is shown.
- **Restart now reopens the family tree that was open**, even when "Automatically load last family tree" is off in Preferences.
- **Glade files open in a text editor.** Double-clicking a Glade file on the Gramps Constants tab now opens it with the program set for Glade files, or else with the text editor. Before, the desktop often passed it to the web browser (the program for XML files), which saved a copy in the Downloads folder instead of showing it.
- **Fixed the type filter on the Gramps Constants tab** in languages other than English: it found nothing, because it compared the English type name with the translated one.
- **Show catalog text** check boxes replace "Hide text not in the catalog" on the Windows sub-tab of the Translation Preview: one check box for each status (translated, same, pattern, ambiguous, not in catalog), each with a tooltip that explains the status. All are selected at first; your choice is remembered in `EnvironmentInspector.ini`.
- **Language in the column titles.** On the Translation Preview tab, the Current and Preview columns name their language, for example "Current (Danish)". A column that would only repeat the language of a column to its left is hidden; for example, Current is hidden in a US English session, because it would repeat Original. **Copy table** copies only the visible columns.
- **Spell checking mismatch is shown.** Gramps chooses the spelling dictionary from the system locale, not from the interface language. The Dictionary row of the Locale Settings tab is marked when the two differ, and the restart dialog mentions it.
- **Glade Interface type** on the Gramps Constants tab. It replaces "Glade interface layout file" and now includes every Glade constant, such as `GLADE_DIR`, so the type filter finds them together.
- Double-click anywhere on the **Gramps Translations** heading row to expand or collapse the list. A single click on its icon still copies.
- The **Current Locale** fields on the Language tab are now aligned in two columns.
- The change log now ends with a list of **Outstanding issues**, sorted into planned work, ideas that need discussion, and limits of Gramps itself, with links to the developer discussions.

## 2.0.0 (2026-10)
- **New Translation Preview tab.** Choose any installed Gramps translation and see how Gramps text looks in that language, without changing the running session. Gramps cannot switch its interface language while it runs, so this tab uses a separate locale for the preview language and leaves everything else untouched.
- **Samples** sub-tab: common Gramps words, a sample date in every date format, the date modifiers (about, before, between), a sample name, and a short list sorted by the collation rules of each language, side by side in the original (English) form, the session language and the preview language. Each sub-tab is rebuilt when it is shown after the preview language has changed.
- **Windows** sub-tab: pick the main window, any window from the Windows menu (editors, dialogs, tools, detached gramplets), the visible sidebar or bottombar gramplet of the active view, or an open Dashboard gramplet. Its interface text (window title, labels, tab labels, column headers, tooltips) is looked up in the catalog of the preview language. Text built at run time, such as "Edit Person (Smith, John)", is matched by its pattern and filled in. Each row shows the original (English) source text next to the current and preview text, and a status: translated, same, pattern, ambiguous or not in catalog. **Hide text not in the catalog** removes rows that are genealogy data or text from other sources. **Copy table** copies the list as tab-separated text.
- **Wrap long text (up to 5 lines)**, on by default: long text in the Original, Current and Preview columns wraps to the column width, and the row grows to as many as five lines; longer text ends with an ellipsis. Rows are re-wrapped when a column or the window is resized.
- The preview only reads interface text. It never reads or changes the contents of text entries, which hold genealogy data.
- **Gramps Translations table.** The collapsible language list is now a sortable table with columns for the current language, a region flag, the code, the language name, the endonym (the name of the language in that language, taken from its own Gramps translation) and the number of translated strings. The flag shows the region named in the translation code (such as pt_BR) or else the region that Gramps pairs with the language for Windows; languages without either have no flag. The table is filled the first time it is opened, and **Copy** on the section icon copies it as tab-separated text.
- **Language for the next Gramps start.** Double-click a language in the Gramps Translations table to use it for the next start of Gramps; the row shows a reload icon and **Restart** until then, and double-clicking it again cancels it. Gramps then offers to restart right away: it closes normally, including the backup on exit, and starts again in the chosen language. The choice is a one-off: the start after that uses the default language again, and the **Restart** marker is cleared. Gramps chooses its language only at startup, from the `LANGUAGE` environment variable; if you choose **Later** on Linux, the next start from the desktop menu uses the language once, through a temporary user copy of the Gramps desktop entry (`~/.local/share/applications/`) that Environment Inspector removes again when Gramps next loads it. Only a copy made by Environment Inspector is ever changed or removed; starting Gramps from a terminal is not affected. The restarted Gramps writes its terminal messages to `environment-inspector-restart.log` in the Gramps cache folder (`~/.cache/gramps/` on Linux), because the terminal it was started from has returned to the shell prompt by then. The pending choice is saved in `EnvironmentInspector.ini` next to the module.
- The Gramps Translations table fills the height of the Language tab as the window is resized, selects the current language when it is first filled, lists the current language first by default, keeps the selected row (or else the current language) centered when it is re-sorted, and selecting a language there also selects it as the preview language on the Translation Preview tab (and the other way round).
- **Current Locale** shows the **Endonym** of the session language after the English name, and **English Name** now always shows the English name (exonym); in a session in another language it showed the name in that language.
- The **Translation Preview** tab is now next to the **Language** tab.
- **Fixed the language list on Linux distribution packages.** The Language tab listed every folder of the system-wide locale directory (703 on Fedora 44) and showed most of them as "Unknown". It now lists only languages that have a Gramps translation, using the same engine call as the language choices of Gramps itself, and the heading reads **Gramps Translations**.
- **Fallback icons.** The `cs-language` (Cinnamon) and `glade-brand-symbolic` (Glade) icons are bundled in the `media` folder, with provenance metadata, and are used only when the active icon theme does not have them.

## Outstanding issues
Known gaps, sorted by what can be done about them. Most come from the developer discussion [Gramps Restart-and-Restore Mechanism, including Language Preference](https://github.com/gramps-project/gramps/discussions/2467) and the forum thread [Change between language: a GUI enhancement?](https://gramps.discourse.group/t/change-between-language-a-gui-enhancement/7060).

### Planned / not yet implemented
- **Code snippet generator.** For addon developers: choose a row on the Gramps Constants tab and get the Python lines that import and safely use that constant, following the patterns in the [Constants](media/EfficientConstants.md) reference.
- **Language names in the Translation Preview list.** The list will show the name of each language in that language (the endonym), as the Gramps Translations table already does.

### Needs discussion
- **Restart on Windows.** Automatic restart works only on Linux and macOS. Windows needs a different way to start the new Gramps, because the usual method has trouble with folders such as "Program Files" that contain spaces ([details](https://github.com/gramps-project/gramps/discussions/2467#discussioncomment-17655076)).
- **Making spell checking follow the interface language.** The restart could also change the system locale (`LANG`), but that changes dates, numbers and sorting too, which many people do not want. A fix inside Gramps has been proposed instead ([discussion](https://github.com/gramps-project/gramps/discussions/2467#discussioncomment-17643505)).
- **Sorting and date format for each tree.** The sort order and the date format are the same for every tree, so a tree about Swedish ancestors cannot keep Swedish sorting while another tree uses English sorting. Moving these settings into each tree, like the custom name formats, has been suggested ([proposal](https://github.com/gramps-project/gramps/discussions/2467#discussioncomment-17638595)).
- **A language icon.** Gramps has no widely recognized language icon, so a person who started Gramps in a language they cannot read has no visual clue for where to change it back. Whatever icon Gramps adopts could also be used on the Gramps website, wiki and forum ([discussion](https://github.com/gramps-project/gramps/discussions/2467#discussioncomment-17642565)).

### Beyond scope
These need changes to Gramps itself.
- **No language choice inside Gramps.** Gramps has no language setting in Preferences and no command-line option for the language; it chooses its language once, at startup, from the `LANGUAGE` environment variable or the language of the system. A language preference with an automatic restart, and a command-line option, are being discussed for a future Gramps ([proposal](https://github.com/gramps-project/gramps/discussions/2467), [command-line option](https://github.com/gramps-project/gramps/discussions/2467#discussioncomment-17640244)). Until then, Environment Inspector can choose the language for the next start.
- **Some Preferences need a restart, but Gramps does not offer one.** Date format, Age display precision, Display ages for events after death and Show text labels beside Navigator buttons are marked with an asterisk (*). After changing one of them, Gramps only shows a reminder ([forum thread](https://gramps.discourse.group/t/preferences-that-require-restart/7464)).
- **Special sort orders have no setting.** Variants such as the German phone book order are only available with PyICU installed and the `COLLATION` environment variable set before Gramps starts (for example `COLLATION=de_DE@collation=phonebook`).
- **Right-to-left text is all or nothing.** Text direction follows the interface language for the whole window. A single field, such as a name in Hebrew or Arabic, cannot be entered right to left while the rest of Gramps stays left to right.
