## 1.0.0 - 2026-10-29
First release, for Gramps 5.2, 6.0 and 6.1.
### Added
- A **Role Reversal** custom filter rule for people, in the Event filters category. It finds people with the Primary role in an event where another person or family holds a chosen role, for example Godparent.
- A **Role Reversal** custom filter rule for families, in the Event filters category. It finds families with the Family role in an event where a person or another family holds a chosen role, for example Witness.
- A **Shared with role** box with the standard event roles and the custom roles used in the family tree. Any role can be typed. Leave the box empty to match any role.
- Standard roles are saved by their English names, so saved filters keep working when the language of Gramps changes.
